# SeleniumPratice

## Project Overview
A Selenium WebDriver automation practice project using Java and Maven.

## Technologies Used
- Java
- Selenium WebDriver
- TestNG
- Maven
- Git and GitHub

## Framework Features
- Page Object Model (POM)
- Data-driven testing using TestNG DataProvider
- Configuration management using properties files
- Browser initialization using BrowserFactory
- Reusable wait utilities
- Screenshot utilities
- JavaScript utilities
- Logging

## Project Structure
- `src/test/java` - Test classes and supporting Java code
- `config.properties` - Test configuration, if present
- `testng.xml` - TestNG suite configuration
- `pom.xml` - Maven dependencies and build configuration

## How to Run
1. Clone the repository.
2. Import the project into Eclipse as a Maven project.
3. Verify the browser and test configuration.
4. Run the required TestNG test or test suite.

## Purpose
This project is used to practice Selenium automation,
test framework design, and Git version control.
